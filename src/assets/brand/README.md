# Markenzeichen

Die Dateien in diesem Ordner wurden **aus dem gelieferten Originallogo abgeleitet** und
nicht neu gezeichnet. Farben, Proportionen und die gelbe Bewegungslinie stammen
unverändert aus der Vorlage.

| Datei | Verwendung |
|---|---|
| `im-cargo-mark.png` (952 px) | Bildmarke, Kopfzeile, Fußzeile |
| `im-cargo-mark-{512,192,180,96,48,32,16}.png` | App-Icons, Favicons |
| `im-cargo-mark.webp` | kleinere Variante der Bildmarke |
| `favicon.ico` | Favicon (16/32/48) |
| `im-cargo-wordmark-navy.png` | Wortmarke auf hellem Grund |
| `im-cargo-wordmark-white.png` | Wortmarke auf dunklem Grund |
| `brand-line.svg` | Bewegungslinie aus dem Logo, als Gestaltungselement |
| `og-image.jpg` / `.webp` | Vorschaubild für Social Media und Messenger (1200 × 630) |

## Wichtig

Die Vorlage lag nur als Rastergrafik vor. **Sobald das Original als Vektordatei
(SVG, EPS oder AI) verfügbar ist, sollte es diese PNG-Dateien ersetzen** – Dateinamen
beibehalten bzw. im Markup auf `.svg` umstellen. Dadurch wird die Darstellung auf
hochauflösenden Bildschirmen und im Druck schärfer.

## Farben

| Farbe | HEX | Verwendung |
|---|---|---|
| Navy | `#071A2F` | Grundfarbe, Flächen, Text |
| Gelb | `#F2C400` | Akzent, primäre Aktionen, Bewegungslinie |
| Weiß | `#FFFFFF` | Schrift auf Navy, Eingabefelder |

Das Logo darf nicht verzerrt, eingefärbt oder mit Effekten versehen werden.
